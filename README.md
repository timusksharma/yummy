# Yummy

Yummy is an interactive kitchen companion for recipe discovery, ingredient matching, weekly meal planning, grocery lists, nutrition guidance, and practical kitchen tools.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

All personal state is stored locally in the browser. The ingredient scan and Ask Yummy experiences are clearly labeled local demonstrations and do not contact an AI service.
